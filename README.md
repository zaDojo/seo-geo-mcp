# zaDojo plugin

The zaDojo plugin and SEO skills for Claude Code, Codex and Cursor. It connects your agent to [zaDojo](https://zadojo.com) for keyword research, competitor research, backlinks, site audits, rank tracking and AI visibility.

## Install

Claude Code:

```
claude plugin marketplace add zadojo/zadojo-plugins
claude plugin install zadojo@zadojo
```

Codex:

```
codex plugin marketplace add zadojo/zadojo-plugins
```

Full setup guides: [zadojo.com/docs](https://zadojo.com/docs/agent-setup).

The skills live in [`plugins/openseo/skills`](plugins/openseo/skills).
